================================================================================
TESSERA-8 INSTRUCTION SET ARCHITECTURE (ISA) & SYSTEM CONSTANTS
================================================================================

1. REGISTERS
--------------------------------------------------------------------------------
A : 0 (0b00)
B : 1 (0b01)
H : 2 (0b10)
L : 3 (0b11)

2. SYSTEM & MEMORY-MAPPED I/O CONSTANTS
--------------------------------------------------------------------------------
PC_RESET    : 0x0000
SP_RESET    : 0x01FF
SRAM_END    : 0x01FF
UART_DATA   : 0xFF00
UART_STATUS : 0xFF01
GPIO_OUT    : 0xFF02
GPIO_IN     : 0xFF03
CYCLES_LO   : 0xFF04
CYCLES_HI   : 0xFF05

3. VARIABLE-REGISTER ENCODINGS
--------------------------------------------------------------------------------
LDI_BASE : 0x10
  Format : LDI r, imm8  -> opcode = 0x10 + r (0x10 - 0x13), Length: 2 bytes, Operand: imm8

MOV_BASE : 0x40
  Format : MOV rd, rs   -> opcode = 0x40 + (rd * 4) + rs (0x40 - 0x4F), Length: 1 byte, Operand: None

4. FIXED OPCODES
--------------------------------------------------------------------------------
Operand Types:
  None  : 1-byte instruction (opcode only)
  imm8  : 2-byte instruction (opcode + 1 immediate byte)
  abs16 : 3-byte instruction (opcode + 2 address bytes, little-endian)

5. STACK CONVENTION (FULL DESCENDING)
--------------------------------------------------------------------------------
Model      : Full Descending Stack (SP points to the top occupied byte)
Reset      : SP_RESET = 0x01FF (empty sentinel; never written by stack ops)
Usable RAM : 0x01FE down to 0x0000 (first pushed byte lands at 0x01FE)

Operations:
  PUSH_A (0x58) : SP <- SP - 1; MEM[SP] <- A
  POP_A  (0x59) : A <- MEM[SP]; SP <- SP + 1
  CALL   (0x5A) : Pre-decrements SP and pushes 2-byte return address; PC <- abs16
  RET    (0x5B) : Pops 2-byte return address into PC and post-increments SP
